# UI 整合重构设计（OBS-3283 → UI-CONSOLIDATION）

> 用户 2026-11-27 15:57 反馈（UI-REFACTOR 已于 cycle 138 结案后仍不满意）：
> **「不要只是收起，基于整个系统做一个完整的重构设计，然后重新排布，同时去除非必要的控件」**。
> 本文档 = 控件盘点 + 冗余分析 + 新布局提案 + 去除非必要控件清单，供用户评审后分阶段实施。

---

## 1. 现状控制面盘点（分区）

| 区 | 控件 | 定位 |
|---|---|---|
| **A 顶部工具条** | Run (ctrl+r) · 清空 · 控制台/代码 tab · 加载 · 保存下载 | 全局主操作 |
| **B 左侧代码面板** | 代码编辑区（console 输出折叠） | 代码区 |
| **C 地图/视口** | 图层透明度 slider · 分享视图 · 2D/3D/GIS/MARS 切换 · 经纬度/高度/相机读表 | 视口 overlay |
| **D AI 面板（右）** | ①头部：AI Key · 修代码 · 导出 · 清空 · 自动 · >>（折叠）②自然语言栏：🔮自然语言 + 解析 + 一键代码 + 4 筛选 chips（name含/大于/为空/bbox内）+ 📄MD/🌐HTML ③AI 建议快捷 chips ×8（飞到北京/多城天气/飞行路径/3D立方体/画矩形/帮我写代码/修一下/联网搜文档）④消息流（每消息：复制/应用 diff/已调用工具/导出 MD/预览 diff）⑤底部输入 + 发送 + 上传 | 右侧聊天 |

## 2. 冗余 / 可去除非必要控件

| # | 控件 | 问题 | 处置 |
|---|---|---|---|
| R1 | **🔮 自然语言栏**（解析/一键代码/MD/HTML/4 筛选 chips） | 用户明确「没啥用」；与底部 AI 框功能重叠；MD/HTML 导出与「导出当前会话为 Markdown」重复；筛选 chips 仅对结构化过滤有用 | **从主面移除**，并入 AI 输入为可折叠「🔮 筛选」小开关（默认收起） |
| R2 | **AI 建议快捷 chips ×8** | 多城天气/飞行路径/画矩形/帮我写代码/修一下 均可被一句话触发，属「示例」而非独立功能 | 收敛为**单个「💡 建议」弹出**，保留 Top3（飞到北京/3D立方体/联网搜文档）+ 更多 |
| R3 | **消息内常显按钮**（复制/应用/已调用工具/导出 MD/预览 diff） | 每条消息都暴露，视觉杂 | **hover 才显示**，收进单条消息右侧「⋯」菜单 |
| R4 | **导出 / 清空** 两个独立顶按钮 | 都是会话级动作 | 与 **>> 折叠** 合并为「⋯ 更多」菜单（导出/清空/折叠/自动） |
| R5 | **修代码** 独立开关 | 属模式切换，非高频 | 保留但并入模式分组（自动/手动/修代码 三态） |
| R6 | **分享视图** 在视口 overlay | 与顶部工具条分离 | 上移至顶部工具条（与 Run 同组） |
| R7 | 读表（经纬度/高度/相机） | 3 个独立读数分散 | 收敛为**状态栏一行**（统一 font/mono/间距） |

## 3. 新布局提案（分区重构）

```
┌────────────────────────────────────────────────────────────────────────────┐
│ A' 顶部全局工具条（统一高度 40px，右对齐分组）：                               │
│   [Run] [清空] [控制台]   │   [分享视图]   │   [保存/加载]   [⋯ 更多]       │
├────────────────────────────────────────────────────────────┬───────────────┤
│  B' 代码面板（宽 300px，与工具条同高、可折叠）                 │  D' AI 面板   │
│  ┌──────────────────────────────┐                          │  头部：       │
│  │ 代码编辑区（console 折叠 tab） │    C' 地图视口（flex 填满）│  [AI Key]     │
│  └──────────────────────────────┘                          │  [自动|手动|修代码]│
│                                                            │  [⋯ 更多]      │
│  C' overlay（悬浮、少而精）：                                 │  消息流：      │
│    图层透明度 · 2D/3D/GIS/MARS                              │  每条 hover→⋯ │
│                                                            │  （复制/应用/工具）│
│                                                            │  输入：       │
│                                                            │  [💡建议][🔮筛选]│
│                                                            │  [文本输入][发送]│
├────────────────────────────────────────────────────────────┴───────────────┤
│  E' 状态栏（一行）：经纬度 · 高度 · 相机（mono 等宽）                          │
└────────────────────────────────────────────────────────────────────────────┘
```

**要点**
- **去除非必要控件**：自然语言栏主面移除（R1）、快捷 chips 收敛为建议弹窗（R2）、消息内按钮 hover 化（R3）、导出/清空折叠（R4）、读表状态栏化（R7）。
- **重新排布**：顶部工具条统一分组；分享视图上移（R6）；AI 面板以聊天为核心，功能收进「⋯ 更多」与「建议/筛选」弹层。
- 视觉层复用既有 token（Geo Dark/Light + `--fs-*` + 语义色），不新增框架；双主题全程不破。

## 4. 实施阶段（每阶段独立可交付/可验证，均在 feat/auto-cycle）

| 阶段 | 内容 | 验收 |
|---|---|---|
| **UC-1** | 顶部工具条统一分组：分享视图上移、加载/保存并入、导出/清空/折叠入「⋯ 更多」 | 顶栏高度一致、分组清晰；功能零回归；15/15 门禁 |
| **UC-2** | AI 面板重排：快捷 chips →「💡 建议」弹层；自然语言栏 →「🔮 筛选」可折叠（默认收起） | 主面仅剩 输入+发送+建议/筛选；R2 弹层可开合；零回归 |
| **UC-3** | 消息渲染收敛：per-message 按钮 hover 化、冗长 tool 结果默认折叠、代码块高亮、markdown 排版 | hover 出菜单；长结果可折叠；双主题核对 |
| **UC-4** | 状态栏收敛：读表统一一行（经纬度/高度/相机）+ 视口 overlay 精简 | 读表单行；overlay 仅必要控件 |
| **UC-5** | 全量回归 + 浏览器视觉核对（需用户参与确认） | 172/172 + 15/15 门禁 + 用户视觉 sign-off |

## 5. 风险与约束
- 纯表现层重构：**不改业务逻辑/协议/对外接口** → 非高风险，但视觉变化大，需用户对**设计提案**与**最终视觉**分别 sign-off。
- 若某阶段需删控件，先确认无隐藏功能依赖（事件 handler 唯一性 + 用途注释）。
- 每阶段提交在 `feat/auto-cycle`，禁止直推 main；双主题（Geo Dark/Light）全程不破。
