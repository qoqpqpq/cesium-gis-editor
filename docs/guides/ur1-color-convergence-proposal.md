## 基线更新

| 指标 | cycle-38 基线 | cycle-64 当前 |

- 本轮（cycle-64）新增 7 个中性色 token（`--color-white/black/gray-300/gray-500/gray-600/slate-100/slate-400`），迁移 25 处同值中性色（`#888`×8、`#94a3b8`×6、`#fff/#ffffff`、`#4b5563`、`#000`、`#d1d5db`、`#f1f5f9`，含 `var(--token, #hex)` 回退位），组件硬编码 **250→238**。
- 注：多数中性色为 `var(--token, #hex)` 的**防御性回退值**（非主样式），已改为 `var(--token, var(--color-*))`（等值零视觉变化）。

## 达成 −50% 的口径
- 剩余复用色（主题深色 22 + 状态/图表 ~23）全部 token 化 → 238 − 45 ≈ **193**（需再加单次色部分归并才能到 ≤183）。
