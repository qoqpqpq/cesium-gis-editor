# Cycle-113 开发日志

## 上下文
3a（shadow）已于周期 112 结项。本轮按用户拍板执行 3b（间距语义阶梯）。关键决策：非网格间距值（1/2/3/5/6/10/14/18/28/30px）无法对齐 4px 网格语义档而不改变观感，故**不强行归并**（会变视觉），而是以值命名档 `--space-<N>px` 如实保留（诚实边界，延续 cycle-68/71/75 结论），仅把既有 `--gap-*` 全部改为 `--space-*` 纯别名。

## 实现
1. 审计：`--gap-*` 16 个定义、264 处引用、无 theme.css 覆写、无 JS 内联引用。
2. 建 `--space-1..6`（4/8/12/16/20/24px 语义档）+ 10 个 `--space-<N>px` 值命名档为规范定义。
3. `--gap-1..4`、`--gap-*px` → `var(--space-*)` 纯别名（计算值逐一对等）。
4. 门禁：新增 spacing-token-semantic-ladder（5 条），与既有 CSS 门禁全绿。

## 风险与边界
- 别名层是 var() 间接，不引入值重复；`--space-*` 值唯一。
- 若后续要"归并非网格值"，属视觉变化，需另立设计拍板（本次不做）。
