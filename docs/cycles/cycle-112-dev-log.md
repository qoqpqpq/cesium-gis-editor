## 实现过程

3. 新增门禁 spec 时首版 `ruleBlocks` 解析器把声明行误当选择器（把 `--code-bg: rgba(...)` 当成 selector），导致 G2 误报 24 条；重写为严格 depth 配对 + 引号串跳过，复跑 6/6。
4. 变异测试确认门禁真实生效（G1/G4 命中），再还原。

## 关键判定记录
